# 밑줄상점

**Shop texts. Show yourself.** — 패션을 쇼핑하듯, 문장을 쇼핑하다.

마음에 드는 문장을 장바구니에 담고, 5개가 모이면 나만의 취향 무드보드가 만들어지는 문장 편집숍입니다.
교사 대상 바이브코딩 해커톤(주제: 텍스트 힙) 출품작입니다. 기획서는 `../plan/밑줄상점_PRD_v0.3.md`를 따릅니다.

## 기능
- three.js 상점 외관 첫 화면 (불 켜짐 → 간판 → 밑줄 → 슬로건 → 문 열고 입장)
- 구글 간편 로그인 + 닉네임 (실명 대신 닉네임만 공개)
- 화이트 에디토리얼 디자인(팀 시안 반영): 2단 헤더+메뉴 탭, 3장씩 넘기는 추천 배너, 분위기 바로가기, 숫자형 TOP 100 그리드, 분위기별·사용자별 피드, 1열/2열 보기, 주황 물결 브랜드 밑줄
- 내 무드보드(IMAGE·COLOR·TYPOGRAPHY·TEXTURE·KEYWORD) 섹션과 /mood, 신상 페이지(/new)
- 오늘의 문장 TOP 100 (오늘 담긴 수 기준, 부족하면 누적/데모로 구분 표시)
- HOME: 오늘의 추천 문장, 많이 담기는 밑줄, 책 진열대, 해시태그·검색·정렬(최신순/많이 담긴 순) 메이슨리 피드
- EXPLORE: 분위기 섞어 보기, 큐레이션 5종, 장바구니와 비슷한 문장, 고전 컬렉션, 초성 색인 책 목록
- 책 상세: 한 권의 밑줄 피드, "나와 비슷한 취향" 필터, 밑줄 올리기 버튼
- 문장 상세: 형광펜 밑줄 연출, 게시자 한마디, 하단 고정 담기 바, 같은 책·비슷한 분위기 추천, 복사·신고·내 밑줄 지우기
- POST: 책 → 문장 → 스타일(글꼴·색·질감·장식) → 키워드 → 미리보기 5단계, 책 자동완성, 스타일·키워드 자동 추천
- CART: 취향 분석까지 진행 막대, 5개 담으면 분석 연출 후 무드보드 생성, 담기/빼기마다 갱신, 이미지 저장, 셋로그 남기기
- DRAWER: 내가 올린 밑줄(담긴 횟수), 지금까지 담은 문장, 셋로그 타임라인
- 나를 표현하는 무드보드: 문장 카드·내가 쓴 글·키워드·색 견본·스티커·테이프를 자유 배치(끌기·돌리기·크기·레이어), 배경 8종, 취향 분석으로 초안 시작, 자동 저장, 이미지 저장, 갤러리 공개와 개인 보드 페이지(/b/:uid)
- 안전: 금칙어·전화번호·이메일 차단, 신고 3회 누적 시 자동 숨김 (Firestore 규칙으로 강제)
- 고전 시드 문장 32개 자동 진열 (저작권 보호 기간이 끝난 작품, 외국·한문 작품은 직접 옮김)

## 취향 분석
지금은 규칙 기반입니다(`src/lib/taste.js`의 `analyzeTaste`). 담은 문장의 키워드 빈도로 제목·요약·팔레트·분위기 비율을 만듭니다.
Claude API로 바꾸려면 Firebase를 Blaze 요금제로 올리고 Cloud Functions에서 같은 형태의 JSON을 돌려주도록 `analyzeTaste`만 교체하면 됩니다.
